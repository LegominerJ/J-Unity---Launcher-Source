# Welcome to J-Unity - Launcher Source!

This repo tracks the releases of and the online files fetched by the J-Unity Launcher.

The J-Unity Launcher allows for a seamless, unified experience for the J-Unity games.

Download, extract, and run the latest Launcher.exe and select between a Standalone install and a Portable version. After setup, you're ready to choose a game and play!

Have fun! :)
